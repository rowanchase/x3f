# Phase 1 Experiments - 2026-04-03

## Goal
Replicate darktable's processing to improve x3f_extract output to match SPP.

## Initial Assessment

| Output | RMSE | Saturation |
|--------|------|------------|
| x3f_extract (baseline) | 17.12 | 0.127 |
| darktable + XMP | 19.14 | 0.218 |
| SPP reference | 0 | 0.088 |

**Key finding:** darktable output is actually *worse* than current x3f_extract!

## Experiments Conducted

### Experiment 1: Global Desaturation Only
- Reduced desat_factor from 1.7 to 0.7
- Result: RMSE increased from 17.12 to 17.30 (worse)
- Conclusion: Simply reducing saturation doesn't help in isolation

### Experiment 2: Channel Mixer Only (darktable matrix)
- Applied matrix:
  ```
  R_out = 1.00*R + 0.00*G + 0.05*B
  G_out = 0.06*R + 1.00*G - 0.05*B
  B_out = -0.33*R + 0.09*G + 1.08*B
  ```
- Result: RMSE increased from 17.12 to 19.00 (much worse)
- Conclusion: Matrix not appropriate for all files

### Experiment 3: Combined Desaturation + Channel Mixer
- desat=0.7 + channel mixer
- Result: RMSE 16.69 (0.43 better than baseline)
- BUT: Caused regressions on other files:
  - _P2M0927: 14.64 (worse than baseline)
  - _P2M0994: 11.48 (worse than baseline)
  - _P2M1008: 17.54 (worse than baseline)

## Key Learnings

1. **Darktable output is not a good reference** - it's worse than current x3f_extract
2. **Per-scene optimization doesn't generalize** - the darktable XMP was tuned for one specific image
3. **Channel mixer causes regressions** - needs per-camera/per-ISO matrices
4. **Saturation alone isn't the answer** - needs coordinated color matrix changes
