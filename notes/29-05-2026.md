# 2026-05-29 - CSF Analysis & Variant 5 Implementation

## Question: Is CSF applied to the right data?

The user asked whether CSF should be applied to raw sensor layer data or after CCM/sensor cross-talk fix.

### Investigation

**Full pipeline architecture (x3f_process.c):**
1. Line 931: CSF was designed to be applied BEFORE CCM (raw space), multiplied with spatial gain and per-channel multipliers. BUT line 923 comment: "ColorShadingFactor disabled - causes regression"
2. Lines 948-956: The 7x7 Merrill spatial color correction is applied AFTER CCM in RGB output space — and this WORKS.

**Why raw-space CSF breaks:**
CCM (AutoCCMatrix) has massive off-diagonal terms:
- G_out = -1.68*R_in + 3.53*G_in - 0.85*B_in
- Small ±3% modification to R_in gets inverted (-1.68×) and amplified into G_out
- This creates wild spatial color swings: reducing R_in boosts green output

**Why output-space correction works:**
Channels are independent in RGB space. Applying a correction factor to R channel only affects R output.

### Variant 4: Multiply CSF in output space (full gradient)

Implementation: Apply `output[0] *= (1 + R_col*col_norm + R_row*row_norm)` after CCM.

Results (vs baseline no-CSF):
```
            Baseline              Variant 4
Top:    G-R=+3.8 G-B=-0.0    G-R=+5.0 G-B=+0.5
40%:    G-R=+1.0 G-B=+0.3    G-R=+0.5 G-B=-0.0
Bot:    G-R=+7.5 G-B=+8.9    G-R=+5.2 G-B=+7.6
```

- Bottom green cast reduced: G-R 7.5→5.2 (30%)
- BUT created U-shaped pattern (green at top too)
- Column gradient (-0.064 for R) causes overcorrection at top-left

### Variant 5: Multiply CSF in output space (row-only gradient)

Implementation: `output[0] *= (1 + R_row*row_norm)` — zero out column component.

Results:
```
            Baseline              Variant 5
Top:    G-R=+3.8 G-B=-0.0    G-R=+2.4 G-B=-1.0
40%:    G-R=+1.0 G-B=+0.3    G-R=-0.1 G-B=-0.3
Bot:    G-R=+7.5 G-B=+8.9    G-R=+2.7 G-B=+5.0
```

**Dramatic improvement:**
- Middle region now color-neutral (G-R=-0.1)
- Bottom green cast reduced 64% (G-R: 7.5→2.7)
- RMSE: 75.15→74.26
- Green cast now nearly uniform across image (~2.5 everywhere)

### Key Findings

1. **CSF must be applied AFTER CCM, in RGB output space.** The CCM's large off-diagonal coefficients scramble any raw-space modifications.

2. **Multiply in output space** is the correct direction. CSF values describe the correction to apply, not a sensor characteristic to normalize out.

3. **Row-only gradient is sufficient.** Column gradient creates unwanted left-right artifacts. The primary spatial issue is vertical (green cast at bottom).

4. **Residual issues:**
   - Global ~70-point brightness offset (~27% darker, affects all channels equally)
   - Residual uniform green cast (~2.5 everywhere) — likely white balance
   - Bottom-right corner hotspot (+4.1) — likely vignetting, needs non-linear/quadratic correction
