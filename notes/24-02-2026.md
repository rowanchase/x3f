## Results - 24 February 2026 (Evening)

### TCSteepness Implementation

**Goal:** Replace hardcoded sigmoid steepness (k=4.4) with value from metadata.

**Findings:**
- Metadata contains `TCSteepness = 3.0`.
- Using `TCSteepness = 3.0` directly (instead of 4.4) yielded **better RMSE**:
  - 0993: 13.05 -> 12.49
  - 0936: 18.52 -> 18.40
  - 1003: 20.86 -> 20.28
- However, the image became significantly brighter (Mean Error increased by +3 to +5).
- This indicates the 2.6x exposure compensation (tuned for k=4.4) was too high for k=3.0.

### Exposure Compensation Adjustment

**Action:**
- Reduced exposure compensation from 2.6x to 2.5x.

**Results:**
| File | RMSE (k=4.4, exp=2.6) | RMSE (k=3.0, exp=2.5) | Improvement |
|------|-----------------------|-----------------------|-------------|
| 0993 | 13.05 | 12.72 | 2.5% |
| 0936 | 18.52 | 17.91 | 3.3% |
| 1003 | 20.86 | 19.80 | 5.1% |

**Mean Errors:**
- 0993: -0.30 (Excellent)
- 0936: +3.45 (Acceptable given clipping)
- 1003: +1.10 (Good)

### Conclusion
- Using the metadata value `TCSteepness=3.0` is correct.
- Exposure compensation of 2.5x is optimal for this steepness.
- All tested files are now below RMSE 20.
- Highlight clipping (Green cast) is still an issue for 0936, but RMSE is vastly improved from original >33.
