### 2. Key Discovery: Global Desaturation
The IQ metrics revealed our saturation was 2x higher than SPP (0.21 vs 0.09). This was likely causing the G-dominant issue since more saturated images tend to have more extreme channel values.

Added global desaturation before the LUT lookup:

```c
/* Global desaturation: SPP has much lower saturation (0.09 vs 0.21)
   Apply stronger global desaturation to reduce oversaturation.
   This also helps reduce the G-dominant percentage. */
{
  double gray = (output[0] + output[1] + output[2]) / 3.0;
  double desat_factor = 0.65;
  for (color = 0; color < 3; color++) {
    output[color] = gray + (output[color] - gray) * desat_factor;
  }
}
```

## Key Insight

The global desaturation was the key missing piece. SPP applies significant desaturation that:
1. Reduces overall saturation (makes colors more muted)
2. Brings channel correlations closer together (G-B: 0.76→0.90)
3. Naturally reduces the G-dominant bias

This is likely part of SPP's "film-like" or "professional" processing that reduces colorimetric accuracy in favor of a particular aesthetic.
