# Session Notes: 2026-02-26

## 2026-02-26: DeltaE Perceptual Color Metrics

### Problem
User observed that saturation metrics were misleading - our output visually looked undersaturated ("nearly grey") even though saturation values matched or exceeded SPP. The existing metrics (RMSE, HSL saturation) don't correlate with perceptual color accuracy.

### Solution
Added DeltaE (CIELAB color difference) metrics to compare_output.py:

1. **CIELab conversion**: RGB → linear → XYZ → Lab using D65 illuminant
2. **DeltaE1976**: Perceptual color difference in Lab space
3. **Per-channel analysis**: L (lightness), a (green-magenta), b (blue-yellow) errors
4. **Regional DeltaE**: Shadows, midtones, highlights analyzed separately
5. **Per-pixel sampling**: Random pixel sampling with RGB/Lab values

### Implementation
- Added `rgb_to_lab()`, `compute_delta_e1976()` functions
- Added `compute_delta_e_by_luminance()` for regional analysis
- Added `compute_per_pixel_delta_e()` for random pixel sampling
- DeltaE enabled by default (use `--no-delta-e` to disable)
- Added `--num-samples N` for controlling pixel samples
- Added `--delta-e-json file.json` for JSON output
- Removed old saturation metrics that weren't useful

### Results for _P2M0927.X3F
- **Mean DeltaE: 81.99** (DeltaE > 20 is visually different)
- **Median DeltaE: 45.45**
- **95th percentile: 375.56**

Per-channel analysis reveals the key issue:
- L (lightness): mean=14.45, max=147.85

The **'a' channel (green-magenta axis)** has massive errors, explaining the green cast. Midtones are worst affected - this explains why colors appear "nearly grey".
