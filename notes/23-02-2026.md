## Today's Work: Highlight Desaturation

### Problem Analysis

Analyzed file 0936 (MaxHist=255, heavily clipped highlights):
- Our highlights had saturation 0.353, reference had 0.052
- Our B/G ratio: 0.704, reference: 0.917
- B channel was 40+ levels too dark in highlights

### Key Insight

**SPP desaturates highlights towards white!** In bright highlights, all RGB channels should be near maximum, creating white. Our output had colored (saturated) highlights.

### Implementation

Added highlight desaturation in `x3f_process.c`:
- Detect bright pixels (max channel > 0.6)
- Gradually bring all channels towards the maximum
- Use quadratic falloff for smooth transition

```c
if (max_channel > 0.6) {
  double desat_factor = (max_channel - 0.6) / 0.4;
  if (desat_factor > 1.0) desat_factor = 1.0;
  desat_factor = desat_factor * desat_factor;
  
  for (color = 0; color < 3; color++) {
    double diff = max_channel - output[color];
    output[color] += diff * desat_factor * 0.8;
  }
}
```
