## Analysis: ISO 400 vs ISO 200

### Key Discovery: Saturation Difference

Discovered that SPP applies ISO-dependent and luminance-dependent desaturation:

| File | ISO | Ref Mean | Ref Sat | Out Sat | Ratio |
|------|-----|----------|---------|---------|-------|
| 1009 | 400 | 70.1 | 2.1 | 49.2 | 0.043 |
| 1003 | 400 | 91.3 | 6.2 | 54.0 | 0.115 |
| 1008 | 400 | 95.1 | 2.9 | 49.8 | 0.057 |
| 0990 | 200 | 67.2 | 3.9 | 34.7 | 0.113 |
| 0993 | 200 | 168.5 | 14.3 | 28.6 | 0.501 |

The saturation ratio (Ref/Out) shows:
- ISO 400 files have ratios 0.04-0.21 (reference is 5-25x less saturated)
- ISO 200 files at similar brightness have ratios 0.11-0.50
- Brighter images have higher ratios (less desaturation)

### Pattern Analysis

1. **Luminance correlation**: Darker images are more desaturated
2. **ISO correlation**: Higher ISO images are more desaturated
3. **ISO 400 specifically**: Very low saturation ratios (0.04-0.21)

### Hypothesis

SPP applies chroma noise reduction that:
1. Increases with ISO setting
2. Increases for darker regions (where noise is more visible)
3. This is implemented as a saturation reduction, not just luminance noise reduction

### Solution Approach

Add luminance-dependent and ISO-dependent desaturation:
- For low-luminance pixels, reduce saturation more
- For higher ISO, apply stronger desaturation overall

## Implementation: Shadow Desaturation

### Approach
Added luminance-dependent shadow desaturation in `x3f_process.c`:
- For pixels with luminance < 0.3, desaturate towards gray
- Desaturation strength increases quadratically as luminance decreases
- Strength factor: 0.7 (tunable)

### Code Added
```c
/* Shadow desaturation: reduce saturation in dark areas
   SPP desaturates shadows to reduce chroma noise visibility. */
{
  double min_channel = output[0];
  double max_channel = output[0];
  for (color = 1; color < 3; color++) {
    if (output[color] < min_channel) min_channel = output[color];
    if (output[channel] > max_channel) max_channel = output[color];
  }
  
  double luminance = (min_channel + max_channel) / 2.0;
  
  if (luminance < 0.3 && max_channel > min_channel) {
    double gray = (output[0] + output[1] + output[2]) / 3.0;
    double shadow_factor = (0.3 - luminance) / 0.3;
    shadow_factor = shadow_factor * shadow_factor;
    
    for (color = 0; color < 3; color++) {
      double diff = gray - output[color];
      output[color] += diff * shadow_factor * 0.7;
    }
  }
}
```
