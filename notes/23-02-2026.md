## Analysis: ISO 400 vs ISO 200

### Channel Ratio Analysis

**ISO 400 files show larger color errors:**
- R/G diff: -0.05 to -0.08 (R too low relative to G)
- B/G diff: -0.05 to -0.09 (B too low relative to G)

**ISO 200 files show similar but smaller errors:**
- R/G diff: -0.03 to -0.08
- B/G diff: -0.04 to -0.07

### Detailed Luminance Analysis

**ISO 400 file (1003):**
- Very dark (0-30): B is +4.6 (shadow desaturation affecting B)
- Dark (30-60): Near perfect
- Lower mid (60-100): R -4.6, B -6.7
- Mid (100-150): R -10.0, B -13.6 (both much too low)
- Upper mid (150-200): G +7.5 (G too high)
- Bright (200-256): G +12.8 (G too high)

**ISO 200 file (0994):**
- Very dark: R -3.3, G -4.5
- Dark: G +1.3
- Lower mid: R -6.4, B -3.9
- Mid: R -9.1, B -9.2 (equal error)
- Upper mid: G +11.8
- Bright: G +8.0, B +12.2

### Key Observations

1. **Mid-tone R/B error is consistent across ISO** - both have R and B too low
2. **ISO 400 has more pronounced B error** - B is -13.6 vs -9.2 in mid-tones
3. **G is too high in upper mid/highlights** for both ISOs
4. **The error pattern is similar** but magnified for ISO 400

The 2.6x exposure compensation may not be optimal for ISO 400.

### 3. Color Matrix Adjustment

### 4. Spatial Gain Variation
Spatial gain may vary by ISO setting.

## Linear Regression Analysis

### ISO 200 (0994):
- R: Ref = 0.9605 * Ours + 4.5  (R² = 0.97)
- G: Ref = 0.9347 * Ours + 5.0  (R² = 0.99)
- B: Ref = 0.9125 * Ours + 3.6  (R² = 0.94)

### ISO 400 (1003):
- R: Ref = 0.8900 * Ours + 13.6  (R² = 0.88)
- G: Ref = 0.8776 * Ours + 9.6   (R² = 0.92)
- B: Ref = 0.7692 * Ours + 24.6  (R² = 0.75)

### Key Findings

1. **ISO 200 has nearly linear relationship** (R² > 0.94)
2. **ISO 400 has non-linear relationship** (R² = 0.75 for B)
3. **B channel needs most adjustment for ISO 400**:
   - Scale factor: 0.77 (vs 0.91 for ISO 200)
   - Offset: 24.6 (vs 3.6 for ISO 200)
   
4. **SPP applies stronger shadow lift for ISO 400**, especially for B channel
   - This reduces chroma noise visibility in higher ISO images

## Solution Implemented: ISO-Dependent Shadow Processing

### Changes Made

1. **Added capture_iso parameter to convert_data()** - passes ISO info for processing

2. **ISO-dependent shadow desaturation strength:**

3. **B channel boost in shadows for ISO 400:**
